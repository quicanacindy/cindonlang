# Cindon Lang
https://quicanacindy.github.io/cindonlang/ 
(articles with audio available from Nov 10, 2026)
Static site for GitHub Pages. to try it locally you can use the Live Server extension of VS Code (opening index.html does not run the JSON files).
Displayable words in an article: `[palabra]` o `[forma conjugada|forma de diccionario]`.
